INPUT

TASK
Write ONE prompt that transfers the STYLE of the reference to a NEW subject chosen later by the user. Extract and preserve: palette, lighting character, camera habits, composition tendencies, materials/textures, rendering technique, grain/post-processing, mood and overall visual language. Do NOT reproduce the scene.

RULES
- Replace the concrete subject with the single placeholder token [SUBJECT] exactly once, where the subject naturally appears (almost always the first clause).
- Style descriptors must be concrete and transferable: "soft cinematic editorial photography with warm golden-hour grading and restrained contrast", never "nice stylized look".

- If the reference is photographic, express photographic style with hedged camera language; never claim gear.
- Typography: only if lettering is part of the visual language, describe the typographic STYLE as an option; otherwise ignore it.
- Negative prompt: plausible failure modes for STYLE transfer (e.g. "photorealistic rendering" when the style is illustrated). 3-8 items.
- Same banned-words and no-contradictions rules as recreation.

TARGET MODEL GUIDANCE (authoritative):

OUTPUT
